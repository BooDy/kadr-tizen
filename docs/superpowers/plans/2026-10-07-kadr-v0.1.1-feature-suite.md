# Kadr v0.1.1-alpha Feature Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the full Kadr v0.1.1-alpha feature suite on Samsung Tizen OS (TV show multi-season episode browsing, hierarchical folder browser, photo slideshow lightbox, canonical 3-step playback session management, in-player subtitles, private library PIN unlock, and real-time SSE events).

**Architecture:** Modal and overlay stack architecture with spatial D-pad navigation, non-blocking asynchronous REST/SSE communication with Kadr server, and zero-transcode streaming on 1080p canvas.

**Tech Stack:** React 19, TypeScript, Vite (target Chromium 69+), Tailwind CSS, Vitest, React Testing Library, Samsung Tizen AVPlay / HTML5 `<video>`, Lucide React.

## Global Constraints

- Target resolution: 1080p canvas (1920 × 1080) with 10-foot UI scale.
- Tizen compatibility: Chromium 69+ (Tizen 5.5+ / 2020+ TVs).
- Spatial Navigation: All interactions must be navigable using D-pad keys (Up, Down, Left, Right), Enter, Back (`10009`/Escape), and number keys. No mouse dependency.
- Direct-Play Streaming: Zero server transcoding; HTTP 206 range requests with hardware acceleration on TV.
- Zero external build dependencies: Packager must run with vanilla Node.js (`scripts/package-wgt.mjs`).

// tests/player/session.test.ts
import { describe, it, expect, vi, beforeEach, afterEach } from 'vitest';
import { PlaybackSessionManager } from '../../src/player/session';
import { ApiClient } from '../../src/api/client';
import * as playbackApi from '../../src/api/playback';

describe('PlaybackSessionManager', () => {
  let client: ApiClient;

  beforeEach(() => {
    vi.useFakeTimers();
    client = new ApiClient('http://localhost:8492');
    client.setToken('test-token');
    vi.restoreAllMocks();
  });

  afterEach(() => {
    vi.useRealTimers();
  });

  it('starts session, sends 10s progress heartbeats, and cleans up on destroy', async () => {
    const startSpy = vi.spyOn(playbackApi, 'startPlaybackSession').mockResolvedValue({
      session_id: 'sess-123',
      media_item_id: 101,
      duration_seconds: 3600,
      resume_position_seconds: 50,
    });
    const progressSpy = vi.spyOn(playbackApi, 'reportSessionProgress').mockResolvedValue();
    const endSpy = vi.spyOn(playbackApi, 'endPlaybackSession').mockResolvedValue();

    const manager = new PlaybackSessionManager(client);
    const session = await manager.start(101);

    expect(startSpy).toHaveBeenCalledWith(client, 101);
    expect(session?.resume_position_seconds).toBe(50);

    // Heartbeat reporting
    await manager.updateProgress(60);
    expect(progressSpy).toHaveBeenCalledWith(client, 'sess-123', 60);

    // Destroy
    await manager.destroy();
    expect(endSpy).toHaveBeenCalledWith(client, 'sess-123');
  });

  it('handles offline/failure gracefully without throwing unhandled exceptions', async () => {
    vi.spyOn(playbackApi, 'startPlaybackSession').mockRejectedValue(new Error('Network error'));
    const manager = new PlaybackSessionManager(client);
    const session = await manager.start(101);
    expect(session).toBeNull();
    await expect(manager.destroy()).resolves.not.toThrow();
  });
});
